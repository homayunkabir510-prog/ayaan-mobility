# Ayaan Mobility

Enterprise-grade Fleet Management & Dynamic Logbook SaaS — Super-Admin platform,
corporate client portal, driver PWA, and car-owner portal, sharing one Next.js
codebase and one PostgreSQL database.

## Stack

- Next.js 16 (App Router, Server Actions, TypeScript, `src/` directory)
- Tailwind CSS v4 + shadcn/ui
- PostgreSQL + Prisma ORM (Supabase-hosted)
- Zustand for client state
- Supabase Storage / Cloudinary for odometer photos & receipts

## Project structure

```
Ayaan Mobility/
├── CLAUDE.md              # System instructions for AI coding tools (Claude Code, etc.)
├── AGENTS.md              # Auto-generated by Next.js — do not hand-edit
├── .env.example            # Copy to .env and fill in real values
├── components.json         # shadcn/ui config
├── prisma/
│   └── schema.prisma       # Full multi-tenant database schema
└── src/
    ├── app/                 # Routes (App Router)
    ├── components/ui/       # shadcn/ui components land here via the CLI
    ├── lib/
    │   ├── calculator.ts    # calculateDailyDuty / calculateMonthlyInvoice / calculateOwnerPayout
    │   └── utils.ts         # cn() class-merging helper
    └── types/
        └── index.ts         # Re-exported Prisma types
```

## First-time setup

```bash
npm install
cp .env.example .env
# fill in DATABASE_URL, DIRECT_URL, and the Supabase keys in .env

npx prisma migrate dev --name init
npm run dev
```

## Adding shadcn/ui components as you build screens

```bash
npx shadcn@latest add button card input table dialog
```

They land in `src/components/ui/` and use the tokens already wired into
`src/app/globals.css`. Those tokens are a neutral placeholder theme — swap in
Ayaan Mobility's real brand palette when the UI work (Step 4) starts.

## If you're merging this into the existing GitHub repo

Your repo currently has `prisma/schema.prisma` and `lib/calculator.ts` at the
root from the earlier commits. This scaffold uses Next.js's `src/` convention,
so:

1. Extract this package over `C:\Ayaan Mobility`, allowing it to add the new
   Next.js files (`src/`, `package.json`, `tsconfig.json`, etc.) alongside
   what's already there.
2. `prisma/schema.prisma` stays at the project root either way — Prisma looks
   for it there by default, `src/` doesn't change that. It's safe to let the
   new copy overwrite the old one (they're identical).
3. Delete the old root-level `lib/` folder — its one file now lives at
   `src/lib/calculator.ts`.
4. Commit:

```bash
git add .
git commit -m "Add Next.js app scaffold, Prisma/shadcn wiring, and env template"
git push
```
